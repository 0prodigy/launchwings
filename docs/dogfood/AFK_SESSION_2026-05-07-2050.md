## Decision log (Tier 2 actions taken on team consensus or my judgment per CEO authorization)

- **`tsx`-as-production-runtime** for `apps/api` + `packages/agents`: simplifies workspace TS imports, avoids a build step per package, ~300ms cold-start cost is acceptable. Revisit if cold-start data shows it matters.
